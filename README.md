# Black Soil: Agricultural Simulation

Фермерский симулятор про постсоветскую деревню: пашня, посев, уборка, рынок, износ и ремонт техники, сотрудники, сетевая игра до 4 человек. Сделан на Godot 4.7.

Раньше игра называлась Farm Sim.

## Скачать и запустить

1. Открой [Releases](https://github.com/pavel-vireks/agricultural_simulation/releases) и скачай `BlackSoil-<версия>.zip` из последнего релиза.
2. Распакуй куда угодно. `BlackSoil.exe` и `BlackSoil.pck` должны лежать рядом, без pck игра не запустится.
3. Запусти `BlackSoil.exe`.

Если Windows пишет «Не удалось проверить издателя»: до распаковки открой свойства zip и поставь галочку «Разблокировать», либо при запуске нажми «Подробнее» → «Выполнить в любом случае».

Сохранения лежат в `%APPDATA%\Godot\app_userdata\Farm Sim\`. После переименования папка осталась прежней, старые сохранения подхватятся.

## Сетевая игра

- Играть вместе можно только на одной и той же сборке. Версия видна в главном меню, при разных версиях хост не пустит.
- По интернету — через [Radmin VPN](https://www.radmin-vpn.com/ru/). Хост жмёт «Сетевая игра» → «Создать» и присылает свой адрес `26.x.x.x` (кнопка «Скопировать адрес»), остальные подключаются по нему.
- При первом «Создать» Windows спросит про доступ к сети: разреши хотя бы для частных сетей, иначе к хосту не подключиться (порт UDP 24565).

## Управление

Полный список клавиш — в игре, в планшете (H).

| Клавиша | Действие |
|---|---|
| WASD | езда / ходьба |
| Мышь | камера; щелчок колесом — вернуть за спину |
| Shift / Пробел | пешком: бег / прыжок |
| E | сесть в машину или выйти (у чужой машины — пассажиром) |
| I | завести / заглушить мотор (дизель сначала греет свечи) |
| Пробел | ручник |
| Ctrl (удерживать) | курсор для кнопок панели техники |
| F | прицепить / отцепить орудие или прицеп |
| Q | поднять / опустить орудие |
| G | действие на станции: заправка, ремонт, семена, выгрузка, магазин, сон |
| Tab | планшет: рынок, магазин, гараж, карта, земля, бухгалтерия, сотрудники |
| M / H | планшет на карте / на списке клавиш |
| K / L | фары / рабочий свет |
| J / N | полный привод / понижающая |
| T, ↑ ↓ | ручная коробка, переключение передач |
| Z / X, C | ручной газ, круиз-контроль |
| ← → | поворотники |
| V | культура сеялки |
| P | пахать целину плугом |
| U / O | труба шнека комбайна / выгрузка |
| R | поставить машину на колёса |
| F5 / F9 | быстрое сохранение / загрузка |
| Esc | меню |
