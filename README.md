# Farm Sim

Упрощённый фермерский симулятор в духе Farming Simulator: пашня, посев, уборка, рынок, техника, сетевая игра до 4 человек. Сделан на Godot 4.7.

## Скачать и запустить

1. Открой [Releases](https://github.com/pavel-vireks/agricultural_simulation/releases) и скачай `FarmSim-<версия>.zip` из последнего релиза.
2. Распакуй куда угодно. `FarmSim.exe` и `FarmSim.pck` должны лежать рядом, без pck игра не запустится.
3. Запусти `FarmSim.exe`.

Если Windows пишет «Не удалось проверить издателя»: до распаковки открой свойства zip и поставь галочку «Разблокировать», либо при запуске нажми «Подробнее» → «Выполнить в любом случае».

Сохранения лежат в `%APPDATA%\Godot\app_userdata\Farm Sim\`.

## Сетевая игра

- Играть вместе можно только на одной и той же сборке. Версия видна в главном меню, при разных версиях хост не пустит.
- По интернету — через [Radmin VPN](https://www.radmin-vpn.com/ru/). Хост жмёт «Сетевая игра» → «Создать» и присылает свой адрес `26.x.x.x` (кнопка «Скопировать адрес»), остальные подключаются по нему.
- При первом «Создать» Windows спросит про доступ к сети: разреши хотя бы для частных сетей, иначе к хосту не подключиться (порт UDP 24565).

## Управление

| Клавиша | Действие |
|---|---|
| WASD | езда / ходьба |
| E | сесть в машину или выйти |
| Tab | пересесть в другую машину |
| I | завести / заглушить мотор |
| Пробел | ручник (пешком — прыжок) |
| F | прицепить / отцепить орудие или прицеп |
| Q | поднять / опустить орудие |
| G | действие на станции (заправка, склад, магазин…) |
| T | планшет: рынок, магазин, гараж, карта, бухгалтерия, сотрудники |
| K / L | фары / рабочий свет |
| J / N | полный привод / понижающая |
| M, ↑ ↓ | ручная коробка, переключение передач |
| ← → | поворотники |
| V | культура сеялки |
| U / O | труба шнека комбайна / выгрузка |
| Колесо мыши (щелчок) | вернуть камеру за спину |
| H | спрятать подсказки |
| F5 / F9 | быстрое сохранение / загрузка |
| Esc | меню |
